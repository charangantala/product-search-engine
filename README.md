# Product Search Engine

A simple and responsive product search engine built using HTML, CSS, JavaScript, and Algolia Search.

## Live Demo

[View Live Website](https://search-product-engine.netlify.app/)

## About the Project

This project allows users to search for products quickly using Algolia Search.

It provides fast search results with a clean and responsive user interface.

## Features

- Product search
- Fast search using Algolia
- Responsive design
- Product result cards
- Real-time search results
- Modern user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Algolia Search
